Setup

This page is meant for a sighted helper doing one-time setup. After this, the reader itself needs no sight to use.

1. Connect the reading service

Blind Reader uses Claude (an AI by Anthropic) to understand what the camera sees. Either paste an API key here, or run the included server which holds the key for you — see the README.

Note: settings (including the key) are saved per browser, per device. A different browser or phone starts blank — set it up there too, easiest via the setup link at the bottom of this page. Also: the Ask (voice question) feature needs Chrome, Edge, or Safari — Firefox does not support voice input on any website.

Create one at platform.claude.com (API keys section). The key is stored only on this device. Leave empty if you run the server with the key instead.

3. Camera (mainly for PCs)

On a phone the rear camera is picked automatically — skip this. On a PC with more than one camera (laptop camera plus a document webcam), choose the one pointed at the reading material.

Set up another phone without typing

Doing setup for someone else? Fill in this page, then create a setup link and send it to their phone by text message or email. Opening the link on that phone configures the app instantly — nothing to type there.

Tips for the helper

Install the app on the home screen (browser menu → “Add to Home Screen”) so it opens full-screen with one touch. Consider placing it alone on the first home-screen page. Then walk through the Help button together once — the app explains itself out loud (it also gives a spoken tour automatically on the very first tap).

Strongly recommended — lock the phone into this app so a stray touch can never leave it:

  • iPhone: Settings → Accessibility → Guided Access → on. Open Blind Reader, then triple-click the side button to lock the phone into it.
  • Android: Settings → Security → App pinning → on. Open Blind Reader, open recent apps, tap the app's icon → Pin.

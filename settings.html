Setup

This page is meant for a sighted helper doing one-time setup. After this, the reader itself needs no sight to use.

📖 Open the Helper's Guide — plain words, large print, printable. Includes a one-button check of the whole reader. Start there if something isn't working.

1. Connect the reading service

Blind Reader uses an AI vision service to understand what the camera sees. Anthropic Claude gives the best reading quality (recommended for medical and dense material). Google Gemini has a genuinely free tier — good when cost matters most.

How connecting works, in plain words: the "API key" is like a library card from the AI company. You get it once from their website (free for Gemini), paste it below, and the app shows that card whenever it asks for a reading. Readings are counted against that card — never against this app, which has no accounts, no sign-up, and no service of its own. The card is saved only on this device.

More detail, for the technically curious
  • Direct with a key (the default): the key lives in this browser's local storage. Each reading goes straight from this device to the AI provider over HTTPS — api.anthropic.com, generativelanguage.googleapis.com, or api.openai.com. There is no middle server; the app cannot see or log anything.
  • Setup link: "Create setup link" (bottom of this page) packs these settings, key included, into the part of a web address after the # symbol — which browsers never transmit to any server. Opening the link on another device saves the settings there and immediately scrubs the address bar. Treat the link with the same care as the key itself.
  • Server mode: the optional single-file server (server.js, README Option B) holds the keys instead. Devices send readings to it — protected by a passcode and rate limiting — and it forwards them to the chosen provider using its own keys. Works with all three services; phones and PCs then need no keys at all.

Note: settings (including the key) are saved per browser, per device. A different browser or phone starts blank — set it up there too, easiest via the setup link at the bottom of this page. Also: the Ask (voice question) feature needs Chrome, Edge, or Safari — Firefox does not support voice input on any website.

The optional key-holding server (README Option B) works with all three AI services — start it with the matching key(s) and devices need no key at all, just the service choice above.

Set up another phone without typing

Doing setup for someone else? Fill in this page, then create a setup link and send it to their phone by text message or email. Opening the link on that phone configures the app instantly — nothing to type there.

Tips for the helper

Install the app on the home screen (browser menu → “Add to Home Screen”) so it opens full-screen with one touch. Consider placing it alone on the first home-screen page. Then walk through the Help button together once — the app explains itself out loud (it also gives a spoken tour automatically on the very first tap).

Strongly recommended — lock the phone into this app so a stray touch can never leave it:

  • iPhone: Settings → Accessibility → Guided Access → on. Open Blind Reader, then triple-click the side button to lock the phone into it.
  • Android: Settings → Security → App pinning → on. Open Blind Reader, open recent apps, tap the app's icon → Pin.
